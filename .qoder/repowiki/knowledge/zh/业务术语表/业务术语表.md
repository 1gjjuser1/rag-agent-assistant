### 知识库（KB）
- 定义：项目中的独立知识隔离单元，每个 KB 拥有独立的 SQLite 文档记录、Chroma 向量 collection 和 BM25 片段索引，支持创建、切换、删除。
- 别名：kb、知识库ID、kb_id

### RAG
- 定义：检索增强生成（Retrieval-Augmented Generation）。在本项目中指将用户问题经向量+BM25 混合检索召回 Top-K 片段，拼接成带引用标记的上下文后再交给大模型生成回答。
- 别名：检索增强生成

### ReAct Agent
- 定义：推理-行动智能体。通过 Function Calling 让 LLM 在多步循环中选择工具（知识库检索、公司资料、联网搜索），每步执行后收集观察，直到 LLM 判定信息足够再给出最终回答。
- 别名：Agent、工具调用智能体

### 混合检索
- 定义：同时执行向量语义检索与 BM25 词面检索，再通过 RRF（Reciprocal Rank Fusion）融合排序，可选 MMR 去重重排，避免单一检索方式的偏差。
- 别名：向量+BM25、RRF 融合

### 增量入库
- 定义：通过 SHA-256 哈希比对 manifest/indexed_sha 判断文件是否变更，只对新增或修改的文件重新切分并向量化入库，已删除文件的向量会被清理。
- 别名：增量索引、增量索引

### 文档版本
- 定义：同名文件重传时自动升版本号，旧版本文件保留在磁盘 `v<版本>/` 目录下，便于审计与回溯。
- 别名：版本历史、document_versions

### golden set
- 定义：评测集（`evals/golden_set.json`），包含问题与期望答案关键词，用于量化评估检索 hit@k、回答关键词命中率、可溯源率等指标。
- 别名：评测集、黄金集

### 阶段 A / 阶段 B / 阶段 C
- 定义：项目演进路线图：阶段 A 完成多知识库、混合检索、Function Calling Agent、FastAPI 鉴权与评测；阶段 B 规划多租户 RBAC、PostgreSQL、任务队列与观测成本统计；阶段 C 计划接入 MCP 工具、人工审批与模型网关。
- 别名：Phase A/B/C、里程碑
