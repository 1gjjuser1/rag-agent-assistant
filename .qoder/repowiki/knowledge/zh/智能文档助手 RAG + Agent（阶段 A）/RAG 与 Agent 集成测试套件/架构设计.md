测试按被测模块划分文件：`test_store.py` 直接断言 `store.DocumentStore` 的知识库、文档版本、片段与 meta；`test_ingest.py` / `test_ingestion.py` 覆盖增量索引、配置变更触发重建、旧文件迁移等入库逻辑；`test_retrieval.py` / `test_rag_answer.py` 验证向量检索与答案生成；`test_agent.py` 聚焦 ReActAgent 的工具注册表、function calling 循环、流式事件与数据库只读工具；`test_context.py` 与 `test_smoke.py` 提供端到端冒烟用例。

共享基础设施集中在 `helpers.py`（`FakeLLMClient`、`FakeEmbeddings`、`FakeMessage`、`FakeToolCall`、`make_config`、`upload_text`、`ingest_all`）和 `conftest.py`（`pipeline`、`agent` 两个顶层 fixture）。所有测试通过 `tmp_path` 构造隔离的 `AppConfig`，确保每次运行使用独立的 SQLite (`kb.sqlite3`) 与 Chroma 目录，避免状态泄漏。测试依赖方向单向指向被测试包 `rag_pipeline`、`react_agent`、`store`、`config`，不反向引用生产代码以外的任何外部服务。
