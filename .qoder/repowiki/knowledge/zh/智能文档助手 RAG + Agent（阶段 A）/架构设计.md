顶层通过 `app.py`（Streamlit 界面）和 `api.py`（FastAPI REST）两个入口共享同一套核心：`rag_pipeline.RAGPipeline` 提供多知识库上传/增量入库/向量+BM25 混合检索，`react_agent.ReActAgent` 基于 `llm_client.DashScopeClient` 进行 Function Calling 工具调度；两者均依赖 SQLite (`store.py`) 存元数据、Chroma (`vector_store.py`) 存向量、本地磁盘存版本化文档，并通过 `config.AppConfig` 集中读取 `.env` 环境变量。`evals/` 使用相同 RAGPipeline 接口对 golden set 做离线/在线评测，`tests/` 用 pytest mock LLM/Embedding 验证全链路；CI 由 `pyproject.toml` 统一配置 pytest、ruff、mypy 规则，确保三个子模块遵循一致的代码质量与类型检查约束。
