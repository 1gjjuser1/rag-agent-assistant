模块以 `run_eval.py` 为唯一入口，通过 argparse 提供 `--offline` 开关：在线模式直接复用项目根目录的 `rag_pipeline.RAGPipeline` 与 `config.AppConfig.from_env` 调用真实 DashScope Embedding/LLM；离线模式用内置 `_OfflineLLM` 适配器替换 LLM 客户端，并通过 `offline_embedding.OfflineEmbeddings` 生成确定性伪向量（中文 bigram + 英文 token 词袋，256 维稀疏向量），仅验证评测链路而不依赖 API Key。评测流程固定为：创建临时数据目录 → 构建 pipeline → 将 `sample_docs/*.txt` 上传至名为 `eval` 的知识库 → 执行 `ingest` → 逐条读取 `golden_set.json` 中的 question/expected_source/keywords/top_k → 调用 `retrieve` 计算 hit@k，在线模式下再调用 `answer` 计算 keyword_hit 与 citation → 汇总指标写入 `last_run_report.json`。依赖方向单向指向上层 `rag_pipeline` 与 `config`，本模块不暴露对外接口，仅作为可独立运行的脚本存在。
